### 🚗 ひっかけ免許クイズ

運転免許の学科試験に出る「ひっかけ問題」を、ゲーム感覚で対策できるクイズアプリです。高校生などの初学者向けに、ポップな見た目とアニメーションで楽しく学べます。 
<BR>Claude Codeとのバイブコーディングで設計から実装まで一気に作り上げました。

🔗 公開URL:https://driver-license-trick-quiz-ymv7.vercel.app/

※実際の試験とは異なります。正確な内容は教習所等の公式情報をご確認ください。 

### 概要

学科試験の「ひっかけ問題」は初学者が特につまずきやすいため、自動のトラップ感知機能やポップなアニメーションを取り入れ、高校生でも飽きずに楽しく続けられることを目的に制作しました。 

### 主な機能

* **ひっかけトラップ感知灯**: 「必ず」「絶対」などのキーワードを自動検出し、警告灯の点滅と蛍光ペンで強調
* **4つの出題モード**: サクッと10問 / ぜんぶ30問 / ひっかけ特訓 / 苦手克服
* **苦手克服モード**: まちがえた問題を LocalStorage に自動記録し、正解するまで繰り返し復習

### 使用技術

HTML / CSS / React / TypeScript / Vite / Tailwind CSS / Vitest（テスト） / Oxlint 

30問のクイズデータ（○×26問・4択4問）を静的なJSON（src/data/questions.json）で管理しているため、API不要・完全無料で動作します。 

### 工夫した点

* **データ設計**: JAF Mateの交通法規クイズのテーマを参考にしました
* **Git・プルリク運用**: feature/quiz-app ブランチを切り、機能ごとに細かくコミットを分けてプルリクエスト（PR）でマージする流れを徹底
* **バイブコーディング**: AIと会話しながら設計・実装・テストまでを短時間で進め、型チェックやテストで機械的に品質を検証
* **丁寧なバグ対策**: ひっかけ単語の誤検知を防ぐテキスト解析ロジックと、LocalStorageが壊れていても絶対にアプリが落ちない安全設計
