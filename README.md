# ひっかけ免許クイズ (driver-license-trick-quiz)

## 概要

自動車運転免許の学科試験に出る「ひっかけ問題」を、ゲーム感覚で対策できるクイズアプリです。
初めて免許を取る高校生などが、楽しく飽きずに続けられるよう、ポップな見た目と正誤のアニメーションにしました。

- 問題は、アプリ内に静的な JSON として埋め込んでいます(API 不使用・課金なし)
- 問題文と解説は、[JAF Mate「これって違反なの!? 道路交通法クイズ」](https://jafmate.jp/series/safety/traffic_rules_quiz.html)の見出しのテーマ(灯火・駐停車・踏切・自転車など)を参考に、**独自に書き下ろした学習用データ**です(文章は転載していません)
- 実際の試験とは異なります。正確な内容や最新の法令は、警察庁・JAF・教習所などの公式情報で確認してください

## 主な機能

- **ひっかけパターン検出・警告灯**: 問題文の「必ず」「絶対」「常に」「いかなる場合も」などを自動で検出し、画面のすみで「⚠️ひっかけトラップ感知!」の警告灯をピカピカ点滅(Tailwind CSS のアニメーション)。キーワードは蛍光ペンで強調
- **正誤アニメーションと解説**: 正解は pop-in、不正解は shake。答えたあとに「なぜまちがえたのか」を解説
- **苦手克服モード**: まちがえた問題を LocalStorage に記録し、復習できる(正解すると苦手リストから外れる)
- **4つの出題モード**: サクッと10問 / ぜんぶ30問 / ひっかけ特訓 / 苦手克服
- **30問のマスターデータ**: ○×問題 26問・4択問題 4問(`src/data/questions.json`)
- 学習の記録(答えた数・正答率・苦手な問題)の表示、結果画面の称号

## 使用技術

- React 19 / TypeScript(strict・`any` 禁止) / Vite / Tailwind CSS v4
- Vitest(ユニットテスト・描画テスト) / Oxlint

```bash
npm install
npm run dev        # 開発サーバー
npm test           # テスト
npm run typecheck  # 型チェック
npm run build      # 型チェック + 本番ビルド
```

## 学んだこと

- **Git・プルリク運用**: `main` に最初のコミットを置き、`feature/quiz-app` ブランチで開発。機能ごとにコミットを分けて push し、プルリクエスト(PR)を作って `main` にマージする流れ
- **バイブコーディングによる爆速開発**: 要件を会話で伝えて、設計・実装・テスト・Git 操作までを AI と一緒に短時間で進めた。AI が書いたコードも、型チェック・テスト・lint で機械的に確かめることが大事
- **テキスト解析ロジック**: 正規表現のキーワード検出。「必ずしも」「非常に」のように、別の意味の言葉を拾わない先読み・後読みの工夫と、そのテスト
- **型を厳格に保つ設計**: JSON の形を実行時に検証する `parseQuestions`、判別可能なユニオン型(○×と4択)、純粋な reducer による状態管理
- **壊れにくい保存**: LocalStorage の壊れたデータや、使えない環境でも落ちない読み書き
